CWSDPMI release 7 runtime reference

Original archives obtained from the DJGPP distributor:
https://www.delorie.com/pub/djgpp/current/v2misc/csdpmi7b.zip
https://www.delorie.com/pub/djgpp/current/v2misc/csdpmi7s.zip

SHA256SUMS pins both downloaded archives. bin/ contains unchanged supplier
binary-distribution files; manifest/ records the inspected archive inventories.
Only CWSDPMI.EXE and cwsdpmi.doc are installed in C:\FREECIV.
Alternate ring-0/stub variants and configuration utilities are not installed.

CWSDPMI is copyright Charles W Sandmann. Preserve the supplier notices and
redistribution conditions in bin/cwsdpmi.doc. Users have the right to obtain
CWSDPMI source code and/or binary updates; the corresponding source archive
is included here and available at the source URL above.
The binary is unmodified. Use only supplier-authorized tools if modifying its
configuration; do not arbitrarily patch it.

dos_boot_steps.txt in the project root documents installation, one-process
residency, explicit no-paging tests, optional app-local paging, and the tested
DOS configuration. This runtime supply is not proof of Freeciv playability.
