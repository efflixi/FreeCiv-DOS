Project goals:

- Maintain progress tracking so work can resume later.
- Keep the original source archive intact and avoid conversion work until the source tree is understood.
- Define a DOS 6.22 target profile using Pentium 100 / 16MB RAM / VESA graphics and a DOS-native backend strategy.

- Keep the game logic and networking code isolated from the DOS client front-end and sound layer.
