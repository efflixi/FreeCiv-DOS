Freeciv DOS Port Completion Checklist

Goal:
Complete a playable, offline, single-user Freeciv 1.14.1 port for DOS 6.22 using a 32-bit DJGPP/DPMI protected-mode runtime, Pentium 100 / 16 MB RAM, and VESA 2.0+ graphics. Preserve the game rules and reusable engine logic while replacing platform-dependent runtime, GUI, input, and audio layers.

Status note:
This checklist is based on source review, build artifacts, and the supplied documents, not on the completion claims in the old checklist. The project is a prototype, not a playable DOS game. Phase 2 established clean real-backend/isolated-engine linkage; Phase 3 verified DOS boot/deployment/CWSDPMI and separate runtime diagnostics. Phase 4 now implements and visibly verifies real BIOS/DPMI display initialization/presentation/restoration; builds/phase4-dos/ holds the fresh candidate and display evidence. The normal GUI remains gated because game resources, input and production integration are incomplete. Historical source artifacts and previous candidates remain preserved.
